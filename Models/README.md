# Core ML model assets

Place validated compiled Core ML model bundles here before building the app:

- IrodoriTextEncoder.mlmodelc
- IrodoriMeanFlow.mlmodelc
- IrodoriCodecDecoder.mlmodelc

These names are provisional integration slots, not a claim that the upstream Irodori export uses these exact graph boundaries. Confirm the actual exported model names, tensor interfaces, tokenizer, speaker-conditioning inputs, codec configuration, and redistribution license before packaging. Do not commit large model weights without checking repository limits and model terms.
