# PopView

**漫画を、声と動きで楽しむローカル完結型ビューア。**

PopViewは漫画ページを端末に取り込み、Vision OCRでセリフ候補を抽出し、キャラクターごとの参照音声を使ってIrodori-TTSで音声化し、ページ表示と字幕ハイライトを同期するiOSアプリです。

## 開発方針

- iPhone / iPad向けSwiftUIアプリ（iOS 17以降）
- 作品・ページ・キャラクター・参照音声・生成音声を端末内に保存
- Vision OCRと矩形候補検出でセリフ領域を抽出
- Irodori-TTS v4.1 Small MF Core ML版をSwift SDK経由で利用
- 初回起動時にモデルをダウンロードし、SHA-256検証後に端末へ保存
- モデル取得後の音声生成はCore MLでローカル実行
- 動画生成AIや音声生成APIへのクラウド送信に依存しない

## モデル配信

Irodori Swift SDK 0.2.0をSwift Package ManagerのExact Versionで固定しています。
初回起動時にモデルを取得します。iOS 18以降では約1.96 GBの軽量INT8版、iOS 17では約2.99 GBの標準版を選びます。取得時にmanifestのファイルサイズとSHA-256を検証し、モデル一式が完成してからApplication Supportへ配置します。取得後はオフラインで音声合成できます。

モデル取得には通信と数GBの空き容量が必要です。初回のCore MLコンパイル・ロードには時間がかかります。SDK・モデルのライセンスと第三者由来部分はNOTICE / SDK側ライセンス文書を参照してください。

## 技術構成

- SwiftUI: UI / 作品・ページ管理
- PDFKit: PDFページレンダリング
- Vision: OCR・矩形候補検出
- IrodoriTTS Swift SDK: モデル取得・検証・Core ML推論・参照音声
- Core ML: 端末内モデル推論
- NaturalLanguage: 日本語テキスト分割
- AVFoundation: 音声再生

## ビルド

```sh
brew install xcodegen
xcodegen generate
open PopView.xcodeproj
```

GitHub ActionsのiOS Buildワークフローは、XcodeGenでプロジェクトを生成しiOS Simulator向けにビルドします。

## プライバシー

漫画画像、参照音声、生成音声、作品データは端末内に保存します。モデルの初回取得時のみモデル配信先へ通信します。モデル取得後のTTS推論で音声や文章を外部へ送信しません。

## ライセンス

PopView本体とIrodori SDK・Core MLモデル・上流モデルのライセンスは別々に確認します。利用許可のある参照音声のみ登録してください。
