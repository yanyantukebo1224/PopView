# PopView

**漫画を、声と動きで楽しむローカル完結型ビューア。**

PopViewは漫画ページを端末に取り込み、iOS 27以降ではApple Foundation Modelsで画像を直接解析してセリフ・話者・読み順・演技指示を推定します。AI解析が利用できない場合はVision OCRへフォールバックし、キャラクターごとの参照音声を使ってIrodori-TTSで音声化、ページ表示と字幕ハイライトを同期するiOSアプリです。

## 開発方針

- iPhone / iPad向けSwiftUIアプリ（iOS 17以降）
- 作品・ページ・キャラクター・参照音声・生成音声を端末内に保存
- iOS 27以降はFoundation Modelsの画像入力でOCR工程を分離せず漫画ページを直接解析
- Foundation Modelsが利用できない場合はVision OCRと矩形候補検出へフォールバック
- Irodori-TTS v4.1 Small MF Core ML版をSwift SDK経由で利用
- 初回起動時にモデルをダウンロードし、SHA-256検証後に端末へ保存
- モデル取得後の音声生成はCore MLでローカル実行
- 動画生成AIや音声生成APIへのクラウド送信に依存しない

## モデル配信

Irodori Swift SDK 0.2.0をSwift Package ManagerのExact Versionで固定しています。
初回起動時にモデルを取得します。iOS 18以降では約1.96 GBの軽量INT8版、iOS 17では約2.99 GBの標準版を選びます。取得時にmanifestのファイルサイズとSHA-256を検証し、モデル一式が完成してからApplication Supportへ配置します。取得後はオフラインで音声合成できます。

モデル取得には通信と数GBの空き容量が必要です。初回のCore MLコンパイル・ロードには時間がかかります。SDK・モデルのライセンスと第三者由来部分はNOTICE / SDK側ライセンス文書を参照してください。

## 実装状況

### M1 — 漫画ライブラリ
- [x] 作品作成・ローカル永続化
- [x] 画像複数読み込み（拡張子だけに依存せず画像データとして判定）
- [x] PDF全ページのページ化・表示
- [x] ZIP / CBZ / RARアーカイブから画像・PDFを抽出
- [x] フォルダと多階層サブフォルダを再帰走査
- [x] アーカイブ内のサブフォルダ・入れ子アーカイブを再帰走査
- [x] 自然順ソートで「2, 10」などを正しい順番に整列
- [x] ファイル名が不規則な2〜12ページはFoundation Modelsでサムネイルを見て順番を補助推定
- [x] ページ一覧・サムネイル
- [x] 作品単位でページ・音声素材を保存

※RARはUnrar.swift 0.5.4を使用。現在は単一ボリュームのRARに対応し、暗号化RARと分割RARの途中ボリュームは未対応です。ZIP/CBZはZIPFoundation 0.9.20で展開します。アーカイブはパストラバーサル対策を行い、1ファイル160 MiB・合計展開4 GiB・アーカイブ内8,000エントリの上限を設けています。隠しファイル、シンボリックリンク、画像/PDFとして解釈できないファイルは取り込みません。

- [x] iOS 27以降のApple Foundation Models画像入力
- [x] 画像からセリフ本文・話者候補・外見説明をまとめて推定
- [x] 読み順・感情・音声向け演技指示の推定
- [x] セリフ領域の概算座標を生成
- [x] Foundation Modelsが利用できない場合の日本語/英語Vision OCRフォールバック
- [x] 解析結果の編集・話者の手動割り当て

- [ ] 吹き出し座標・話者・縦書きや複雑な漫画レイアウトの精度検証と改善

※iOS 27のFoundation Models画像解析は別途OCRテキストを必要としません。ただし言語モデルが返す吹き出し座標は推定値であり、ピクセル単位の検出結果ではありません。誤読・話者誤認もあり得るため、生成結果の確認と修正が必要です。iOS 17〜26、モデル未準備、解析失敗時はVision OCRへ自動で切り替えます。

## 技術構成

- SwiftUI: UI / 作品・ページ管理 / ファイル・フォルダ選択
- FileManager: 再帰フォルダ走査
- ZIPFoundation: ZIP / CBZ展開
- Unrar.swift: RAR展開
- ImageIO: 拡張子に依存しない画像データ判定
- PDFKit: PDFページレンダリング
- Foundation Models: iOS 27以降のオンデバイス画像理解・構造化解析・不規則なファイル名のページ順補助
- Vision: OCRフォールバック・矩形候補検出
- IrodoriTTS Swift SDK: モデル取得・検証・Core ML推論・参照音声
- Core ML: 端末内モデル推論
- NaturalLanguage: 日本語テキスト分割
- AVFoundation: 音声再生

## ビルド

```sh
brew install xcodegen
xcodegen generate
open PopView.xcodeproj
```

GitHub ActionsのiOS Buildワークフローは、XcodeGenでプロジェクトを生成しiOS Simulator向けにビルドします。ZIPFoundation 0.9.20とUnrar.swift 0.5.4はSwift Package Managerで取得します。

## プライバシー

漫画画像、参照音声、生成音声、作品データは端末内に保存します。モデルの初回取得時のみモデル配信先へ通信します。モデル取得後のTTS推論で音声や文章を外部へ送信しません。

## ライセンス

PopView本体とIrodori SDK・Core MLモデル・上流モデルのライセンスは別々に確認します。利用許可のある参照音声のみ登録してください。
