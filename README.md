# PopView

**漫画を、声と動きで楽しむローカル完結型ビューア。**

PopViewは漫画ページを端末に取り込み、OCR・吹き出し候補検出・話者割り当て・キャラクター音声・同期字幕・2.5D演出へ発展させるiOSアプリです。

## 開発方針

- iPhone / iPad向けSwiftUIアプリ
- 作品・ページ・キャラクター・音声素材を端末内に保存
- Vision OCRと矩形候補検出でセリフ領域を抽出
- Irodori-TTS v4.1 Small MF Core ML版を音声エンジン候補とする
- 音声・字幕・演出をローカルで同期
- 動画生成AIやクラウド処理には依存しない

## 開発環境

- Xcode 16以降を推奨
- XcodeGen

ローカルで xcodegen generate を実行し、PopView.xcodeproj をXcodeで開きます。

## 技術構成

- SwiftUI: UI / ページ・作品管理
- PDFKit: PDFページレンダリング
- Vision: OCR・矩形候補検出
- Core ML: 端末内モデル推論
- AVFoundation: 音声再生
- 将来: Metal / Core Animationによる深度・2.5D演出

## プライバシー

作品画像、参照音声、生成音声は端末内に保存する設計です。コア機能にクラウド送信は必要ありません。
