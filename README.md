# PopView

**漫画を、声と動きで楽しむローカル完結型ビューア。**

PopViewは、漫画画像を解析してキャラクターごとの音声を付け、セリフと同期したカラオケ字幕、2.5D演出を楽しめるiOSアプリを目指します。

## 方針

- iPhone / iPad向けSwiftUIアプリ
- 画像解析・音声合成・描画を可能な限り端末内で実行
- 音声合成候補：Irodori-TTS v4.1 Small MFのCore ML変換モデル（実機互換性・ライセンス・品質を検証して採用判断）
- 吹き出しとOCRテキストを編集可能にする
- セリフの発声タイミングに合わせて文字をハイライト
- 元の漫画絵を維持した2D/2.5Dアニメーション
- 動画生成AIやクラウド処理には依存しない

## 開発環境

- Xcode
- XcodeGen

実行手順：xcodegen generate → PopView.xcodeprojをXcodeで開く。

## プライバシー

作品画像、参照音声、生成音声は端末内に保存する設計を基本とします。外部通信が必要な機能を追加する場合は、明示的な選択と説明を設けます。
